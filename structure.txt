# ============================================================
#  关键文件说明
# ============================================================

【xmcp.config.ts】
  xmcp 框架的主配置文件，定义了：
  - http: true          # 启用 HTTP 传输模式
  - paths.tools          # MCP 工具目录（./src/tools）
  - template.icons       # 工具图标

【package.json】
  项目依赖管理和脚本定义：
  - npm run dev         # 开发模式
  - npm run build       # 生产构建
  - npm start           # 启动服务
  - npm run typecheck   # TypeScript 类型检查
  - npm run clean       # 清理构建产物

【src/lib/ 目录】
  存放可复用的业务逻辑，与具体工具解耦：
  - constants.ts        # 所有常量集中管理，支持环境变量覆盖
  - weather-client.ts   # 天气数据获取，可独立测试
  - hanzi-writer-loader.ts # HanziWriter CDN 加载，可复用

【src/tools/ 目录】
  每个文件是一个独立的 MCP 工具，必须导出：
  - schema              # 输入参数校验（zod schema）
  - metadata            # 工具元数据（名称、描述、CSP 等）
  - default export      # 工具处理函数（返回 UI 或数据）
